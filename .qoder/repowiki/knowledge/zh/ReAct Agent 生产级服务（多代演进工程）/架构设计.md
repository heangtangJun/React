本模块是教学型工程根目录，按 01→06 的演进顺序组织六个子项目：01~03 聚焦算法层（MCP 工具接入、HITL 中断、短期/长期记忆），04~06 将算法封装为生产级服务——04 同步单会话、05 同步多会话+长期记忆、06 引入 Celery 异步任务队列实现并行与故障隔离。跨子项目的统一契约由 `utils/models.py` 中的 Pydantic 请求/响应模型定义，前后端通过 HTTP API（`/agent/invoke`、`/agent/resume`、`/agent/status/{user_id}/{session_id}/{task_id}` 等）交互；RedisSessionManager 提供一致的 Redis key 命名空间（`session:{uid}:{sid}:{tid}`、`task:{tid}`、`user_sessions:{uid}`、`task_mapping:{uid}:{sid}`）并负责惰性清理过期引用；Celery Worker（`utils/tasks.py`）在独立进程中自建连接池、Agent、checkpointer/store，遵循“Worker 任务自包含”原则；前端 `02_frontendServer.py` 用 rich 实现 CLI，承担会话恢复状态机、中断决策 UI 与后端 API 封装。三个进程（celery worker、FastAPI、前端）通过 Redis 作为 broker 和会话状态存储协同，PostgreSQL 仅承载持久化的短期/长期记忆。
