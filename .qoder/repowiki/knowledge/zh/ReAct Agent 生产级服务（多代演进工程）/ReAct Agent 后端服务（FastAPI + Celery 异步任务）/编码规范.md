- 每个模块文件顶部统一通过 `concurrent_log_handler.ConcurrentRotatingFileHandler` 配置同名 logger，并以 `%(asctime)s - %(name)s - %(levelname)s - %(message)s` 格式写入 `Config.LOG_FILE`。
- 所有外部依赖（数据库、Redis、LLM、端口等）集中在 `utils/config.Config` 类中以类属性形式声明，避免散落的魔法字符串。
- HTTP 请求参数与响应体均使用 `utils/models.py` 中定义的 Pydantic BaseModel 进行声明与自动校验，并在路由上通过 `response_model` 标注。
- 会话与任务状态统一通过 `RedisSessionManager` 的 `update_session`/`set_task_status`/`delete_session` 等方法维护，键名遵循 `session:{user}:{sid}:{tid}`、`task_mapping:{user}:{sid}`、`task:{tid}` 等固定前缀约定。
- 长耗时 Agent 执行封装为 Celery `@celery_app.task`，FastAPI 路由仅负责入队并立即返回 task_id，Worker 内部再异步构造 LLM、tools 与 agent 并调用 `agent.ainvoke`。
- 对工具调用统一通过 `add_human_in_the_loop` 包装为支持 accept/edit/reject/response 四种人类干预类型的 BaseTool，再由 `get_tools()` 聚合后注入 ReAct Agent。
