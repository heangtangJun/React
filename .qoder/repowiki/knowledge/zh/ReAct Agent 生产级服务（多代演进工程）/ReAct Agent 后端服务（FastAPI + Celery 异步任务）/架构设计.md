模块以 `01_backendServer.py` 为 FastAPI 应用入口，使用 `lifespan` 在启动时初始化 Redis 会话管理器、PostgreSQL 连接池、LangGraph 的 `AsyncPostgresSaver`（短期记忆）和 `AsyncPostgresStore`（长期记忆），并在关闭时释放资源。

- 请求层：定义 `/agent/invoke`、`/agent/resume`、`/system/info`、`/agent/active/sessionid/{user_id}`、`/agent/sessionids/{user_id}`、`/agent/tasks/{user_id}/{session_id}`、`/agent/status/{user_id}/{session_id}/{task_id}`、`/agent/write/longterm`、`/agent/session/{user_id}/{session_id}`、`/agent/task/{user_id}/{session_id}/{task_id}` 等路由，统一通过 `app.state.session_manager` 操作 Redis 中的会话与任务状态。
- 任务层：`utils/tasks.py` 中通过 `celery_app.task` 注册 `invoke_agent_task` 与 `resume_agent_task`，Worker 进程内创建 LangGraph `create_react_agent`，注入 LLM、工具列表、checkpointer 与 store，并调用 `agent.ainvoke`；结果经 `process_agent_result` 统一转换为 `AgentResponse`（completed / interrupted / error），并通过 `set_task_status` 持久化到 Redis。
- 存储层：`utils/redis.py` 的 `RedisSessionManager` 维护 `session:{user}:{sid}:{tid}`、`user_sessions:{user}`、`task_mapping:{user}:{sid}`、`task:{tid}` 等键空间，并提供 TTL 过期与 `cleanup_user_tasks`/`cleanup_all_tasks` 惰性清理。
- 模型与配置：`utils/models.py` 用 Pydantic 定义所有入参/出参结构；`utils/config.py` 集中管理 DB_URI、Redis、Celery broker、LLM_TYPE、HOST/PORT 等常量。
- LLM 与工具：`utils/llms.py` 通过 `MODEL_CONFIGS` 字典支持 openai/oneapi/qwen/ollama 四种后端，统一返回 `ChatOpenAI` 与 `OpenAIEmbeddings`；`utils/tools.py` 将自定义工具与 MCP Server（高德地图）工具统一包装为带 `HumanInterrupt` 人工审查能力的工具，供 ReAct Agent 调用。

依赖方向：server → tasks → (llms, tools, redis, models, config)；tasks 反向不依赖 server，仅通过 `get_session_manager()` 获取共享会话管理器实例。
